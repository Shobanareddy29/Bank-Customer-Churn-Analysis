# Bank Customer Churn Analysis

## Project Overview
This project analyzes customer churn patterns using SQL on a dataset containing 10,000 bank customer records.

## Tools Used
- MySQL
- SQL
- GitHub

## Dataset Features
- Customer ID
- Credit Score
- Country
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Credit Card Status
- Active Member Status
- Estimated Salary
- Churn Status

## Analysis Performed
1. Customer Distribution by Country
2. Customer Distribution by Gender
3. Average Credit Score Analysis
4. Average Balance Analysis
5. Customer Churn Analysis
6. Average Age by Churn Status
7. Country-wise Churn Analysis

## Key Skills Demonstrated
- SQL Querying
- Data Exploration
- Aggregations using COUNT, AVG and SUM
- Business Insight Generation
- Data Analysis
